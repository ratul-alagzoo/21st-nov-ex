There are various ways to accelerate Python code. Two such mechanisms are implemented in
form of the Python library numba (https://numba.pydata.org) and the C extension framework
Cython (https://cython.org). Read up on one of the two and work through the respective in­
troductory tutorial (https://cython.readthedocs.io/en/stable/src/tutorial/cython_tutorial.html for
Cython, https://numba.readthedocs.io/en/stable/user/5minguide.html for numba).
