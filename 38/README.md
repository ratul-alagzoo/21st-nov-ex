Learn about parameterized tests in pytest. Write a parameterized test for the function
def is_sum_even(x: int, y: int) -> bool:
return (x + y) % 2 == 0
that checks that the sum of two even numbers and the sum of two odd numbers is even, and that
the sum of an even and an odd number is not even.


***Caution: must start with test* prefix
